## Name
Fresh Recs for YouTube

## Summary (max 132 chars)
Tired of the same YouTube recommendations every refresh? Fresh Recs hides videos you've already been shown, so you see something new.

## Category
Productivity (or: Fun → Entertainment)

## Description
Refresh YouTube and get the same videos, just shuffled? Fresh Recs fixes that.

It keeps track of which recommendations you've actually been shown. Once a video has appeared a few times without you clicking it, Fresh Recs hides it, so YouTube fills the space with something you haven't seen.

Features:
• Hides recommendations after they've been shown a set number of times (default 3)
• Hides videos you've already watched
• ✕ button on every recommendation to hide that video for good, with Undo
• Works on the home feed, the watch-page sidebar, and Shorts in feeds
• Hidden videos can return after a cooldown you choose (default 7 days), so nothing is blocked forever unless you hide it yourself
• Dim mode to preview what would be hidden
• Never touches search results, subscriptions or channel pages

Private by design: everything is stored locally in your browser. No accounts, no tracking, no data leaves your device.

Fresh Recs is not affiliated with or endorsed by YouTube or Google.

## Single purpose
Hides repeated or already-watched video recommendations on youtube.com so users see new recommendations.

## Permission justifications
- storage: Saves the user's settings and a local list of which recommended video IDs were shown, watched or hidden, so repeated ones can be hidden on later visits.
- Host permission (www.youtube.com): The content script must run on YouTube pages to detect and hide recommendation cards. No other sites are accessed.
